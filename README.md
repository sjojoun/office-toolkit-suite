# Office Toolkit Suite

免费在线办公工具箱 —— 一站式解决格式转换、图片处理、正则测试、文本批处理、文档互转五大需求。

## 🛠 五大工具

| 工具 | 功能 |
|------|------|
| 🔄 **格式转换** | Base64 / URL / JSON / XML ↔ JSON / CSV ↔ JSON / 时间戳 / 大小写 / 去重排序 |
| 🖼️ **图片处理** | 亮度对比度饱和度 / 翻转旋转裁剪 / 水印 / 导出 PNG/JPEG/WebP |
| 🔍 **正则代码** | 正则测试 + 常用模板 + 代码格式化/压缩（JSON/JS/CSS/HTML） |
| 📝 **文本批处理** | 查找替换 / 分割 / 合并 / 清理空格 / 行号 / 空行 / 排序 / GBK修复 |
| 📄 **文档互转** | DOCX→PDF / PDF→文本 / PDF→Word / 文本→Word / 文本→PDF |

## ✨ 特性

- 玻璃态毛玻璃现代设计
- 深色/浅色主题切换
- 响应式布局（桌面+移动端）
- PDF→Word 排版还原（坐标驱动）
- 大文本分块处理
- 全浏览器端运行，无需后端
